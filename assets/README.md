# Cyber Jum — Asset Inventory

All assets are generated by the scripts in `tools/asset_gen/` (a uv Python
project). To regenerate after editing the scripts:

```sh
cd tools/asset_gen
uv run python generate_art.py
uv run python generate_audio.py
```

**Never hand-edit the files below** — change the generator scripts instead
(sprites are described there as ASCII pixel art, melodies as note lists).

## Art (`sprites/`, `backgrounds/`)

Human-friendly 4x upscaled copies of everything live in [`preview/`](preview/).

## Audio (`sounds/`)

Mono 16-bit WAV at 18157 Hz (a native agb mixer rate). Playable directly in
QuickTime/Finder.

| File | Length | Used for |
|---|---|---|
| `jump.wav` | 0.2s | Player jumps |
| `stomp.wav` | 0.1s | Bouncing on an enemy's head |
| `hurt.wav` | 0.3s | Touching an enemy's side |
| `lose_life.wav` | 0.9s | Losing a life / falling out |
| `win_level.wav` | 0.8s | Reaching the checkered flag |
| `talk_blip.wav` | 0.1s | Dialogue text blips |
| `menu_move.wav` | 0.05s | Moving the menu cursor |
| `menu_select.wav` | 0.2s | Confirming a menu choice |
| `save_chime.wav` | 0.6s | Saving the game |
| `music_title.wav` | 17.5s loop | Title screen (A minor, 110 BPM synthwave) |
| `music_overworld.wav` | 17.1s loop | Top-down world (C major, 112 BPM, cheerful) |
| `music_platform.wav` | 12.8s loop | Cyber Jump levels (E minor, 150 BPM, driving) |

## Font (`fonts/`)

`pixelated.ttf` by codeman38 — the one asset not generated by the scripts.
Used for all in-game text via agb's `include_font!`. Free to bundle with
attribution; see `fonts/license.txt`.
