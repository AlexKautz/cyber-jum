# AI Provenance

This project was generated by an AI coding agent.

## Model

- **Model:** Claude Fable 5 (model ID `claude-fable-5`)
- **Vendor:** Anthropic
- **Tool:** Claude Code (Anthropic's agentic CLI), running in the VS Code
  extension on macOS
- **Date generated:** June 12, 2026
- **Model knowledge cutoff:** January 2026 — details of the agb 0.24 release
  (June 2026) were researched live from docs.rs, the agb book at agbrs.dev,
  and the agb GitHub repository during development.

## What the model produced

- All Rust game code (`src/`), build configuration, and documentation
- All art: drawn as ASCII pixel art / procedural drawing code in
  `tools/asset_gen/generate_art.py` (Python, Pillow), emitted as PNG
- All music and sound effects: synthesized chiptune-style (square/triangle/
  noise) in `tools/asset_gen/generate_audio.py` (Python, NumPy), emitted as
  WAV; melodies are written as note lists in that file
- The five platformer level designs and the overworld map (validated
  programmatically for solvability constraints during development)
- All dialogue and game text

The agent also installed the toolchain (rustup/nightly, agb-gbafix, mGBA),
compiled the game on the development machine, and verified the resulting
`.gba` file's cartridge header and checksum.

## Caveats

The game compiles cleanly and the ROM passes structural verification, but the
agent could not interactively play-test it in an emulator. Logic-level
validation (level solvability asserts, physics/level-design rule matching)
was done statically. If something misbehaves in play, `TESTING.md` describes
how to surface agb's panic messages in mGBA.
